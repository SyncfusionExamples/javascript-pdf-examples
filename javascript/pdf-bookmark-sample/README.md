# How to Add and Remove Bookmarks in a PDF File Using JavaScript

This project is a complete working application to add and remove bookmarks in a PDF file using JavaScript.

## Getting Started

To get started you need to clone the `pdf-bookmark-sample` repository.

```
git clone https://github.com/SyncfusionExamples/javascript-pdf-examples.git
```

## Running

You can run the application by simply opening the `index.html` file in any web browser.
